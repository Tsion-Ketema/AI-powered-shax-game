This is AI Powered Shax game, which can be played in a board between two players in a deterministic environment, This project applies techniques such as Minimax, Alpha-Beta Pruning, and Reinforcement Learning. Additionally, it allows us to analyze decision-making in competitive environments, which is highly relevant to AI research.

The project basically involves two main phases while development.

Phase 1: Implement a Minimax-based agent with Alpha-Beta Pruning to play against a human. 
Phase 2: Train an agent using Reinforcement Learning (Q-Learning/DQN) to adapt, improve and play against human. 

in order to compile and run the front end use the following steps
`cd frontend/`
then `npm install` and finally `npm run dev`.
Make sure you have nodejs installed on your machine.
to check if u have node installed run `node -v` on terminal or command prompt.

This is an AI powered Shax game, which can be played in a board between two players in a deterministic environment, This project applies techniques such as Minimax and Alpha-Beta Pruning. Additionally, it allows us to analyze decision-making in competitive environments, which is highly relevant to AI research.

The project basically involves two main phases while development.

Phase 1: Implement a Minimax-based agent with Alpha-Beta Pruning to play against a human.
Phase 2: Train an agent using Reinforcement Learning (Q-Learning/DQN) to adapt, improve and play against human. (Its is planned to be trained with the minimax versus the montecarlo algorithm).

In order to compile and run AI versus Human mode use the command, `python -m frontend.UI`.
